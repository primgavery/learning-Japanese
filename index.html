    Number building blocks

    Japanese numbers are built compositionally. Learn these pieces and you can read almost any number.

    #ReadingHiragana

    Sound changes to memorize: 300 = さんびゃく (not さんひゃく), 600 = ろっぴゃく, 800 = はっぴゃく, 1000 = いっせん, 3000 = さんぜん, 8000 = はっせん.

    Counters (助数詞)

    Japanese uses different counting words depending on what you're counting — this is the part that trips up Spanish/English speakers, since neither language does this. Each card below shows the full 1–10 pattern and the sound-change rule behind it.
